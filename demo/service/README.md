# sentinel-demo-service

A small order-pricing service. Its pull requests are written the way a coding agent writes them, and every PR is
reviewed by [Sentinel](https://github.com/TianweiZhou/sentinel-ai-code-gate), which tells the human reviewer whether
it can be merged: ✅ Ready to merge, 🟡 Merge after checks, or ⛔ Do not merge.

Conventions for humans and agents are in [CLAUDE.md](CLAUDE.md).
